# User agreement to SadeWiki
SadeWiki is an open source project simply designed to convert markdown files into formatted HTML files and provide them in a format which is hostable on GitHub pages. It's provided with no guarantee or agreements to the end user. SadeWiki is merely a tool.

## What you have to do
If you create a site using SadeWiki, it is your responsibility to:
+ Ensure the content on your site is accurate
+ Confirm any pull requests for any content that may be considered dangerous (malware links, IP grabbers)
+ Confirm any pull requests for any content that may be insight hate
+ Ensure you are using the most up to date version of SadeWiki

## What we have to do
We have to:
+ Take reasonable precautions to not introduce vulnerabilities
+ Be aware of any potential security issues introduced in vulnerabilities (aided by pip audit)

This software is provided with no guarantee.
